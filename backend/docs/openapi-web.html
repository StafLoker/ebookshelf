Ebookshelf - REST API (1.0.0)

Download OpenAPI specification:

REST API of Ebookshelf, a self-hosted ebook library (EPUB and FB2).

Envelope. Every JSON response is {status, message, data, metadata}. status is success or error. metadata appears only in paginated lists. In errors, data is {code, details}.

Authentication. A signed session cookie set by POST /api/auth/login. There is no token in the body.

Error codes.

Code Meaning
AUTH_001 Invalid credentials
AUTH_002 Not authenticated
AUTH_010 Forbidden (role or permission missing)
AUTH_020 Invalid or expired reset token
AUTH_021 Weak password; details lists the missing rules
AUTH_022 Wrong current password (change-password)
AUTH_030 User not found
AUTH_031 Username already taken
BOOK_001 Duplicate book; details.book_id is the existing one
BOOK_002 Unsupported format (only epub and fb2)
BOOK_003 Unreadable or corrupt file
BOOK_004 File too large
BOOK_005 Book not found (also for a pending book the caller cannot see)
META_001 The metadata could not be written into the file
REQ_001 Invalid request
REQ_002 Route not found
REQ_003 Method not allowed
INT_001 Internal error

Create user

Admin or root only. Creates a user with a random password nobody knows and returns a one-time password reset token (valid for 60 minutes) that the new user uses to set their own password through POST /api/auth/reset-password.

Rules:

  • Root can create admins and users.
  • An admin can create users only; creating an admin returns 403.
  • Roles are limited to admin and user. Root cannot be created through the API.
  • Omitted permission flags default to false.
  • Unknown JSON fields are rejected with 400.

Update user

Admin or root only. Only the fields sent are changed; omitted fields keep their current value.

Rules:

  • Root can manage admins and users. Admins can manage plain users only.
  • Root itself cannot be changed by anyone, through this endpoint.
  • Only root can change a role, and only to admin or user. Sending the role a user already has is accepted by anyone who may manage that user.
  • The request body must be a JSON object, even if empty ({}).

List books

Lists the library (status added, default) or pending books, as summaries. Any logged-in user may list the library. Pending books are listed only to their uploader, while admin and root see all of them. q is a case-insensitive substring match on title, author name, tag or identifier value (ISBN hyphens ignored). Order: created (default, newest first) or title.

Replace book metadata

Replaces ALL editable metadata: a field left out is cleared. Needs can_add when the book is pending (only its uploader, admin or root can reach it), can_edit when it is in the library. The file is rewritten with the new metadata, so its hash changes. A library book needs a title, at least one author with a last name, a one-word first name and a year of 1 to 9999. Unknown JSON fields are rejected; the body is limited to 1 MB.
